Elvis Jiang · Information Systems Engineer

Six domains,
one operator.

The platforms, pipelines and data that keep Ara Institute of Canterbury running — engineered, monitored and kept dependable end to end. Here's what sits behind each node on the console.

01DEVOPS

Kubernetes Platform · DevOps

I own the DevOps lifecycle for Ara's Kubernetes platform — building and running the pipelines that deploy applications, manage releases, and keep the cluster healthy through controlled version upgrades.

Alongside the container platform I administer Red Hat systems, using Ansible and related automation tooling to patch, remediate and upgrade at speed — turning one-off fixes into repeatable, consistent operations across the fleet.

  • Kubernetes
  • Deployment
  • Release Mgmt
  • Cluster Ops
  • Red Hat
  • Ansible
  • Upgrades
02SRE

Reliability & Observability

Reliability is a practice, not a dashboard. Prometheus Operator and Grafana give me metrics, dashboards and alerting across the platform, while CheckMK extends coverage to the wider infrastructure.

Between them I monitor every server, Kubernetes container and application, database and network connection — so problems surface as signals I can act on, before they ever reach users.

  • Prometheus Operator
  • Grafana
  • CheckMK
  • Alerting
  • Dashboards
03SIS

Tribal SIS · Maintenance

I maintain the Tribal student management system end to end — keeping data current through scheduled refreshes, running platform upgrades safely, and building the customisations the institution depends on.

It's a business-critical system, so the goal is continuity: every change lands without disruption to the people who rely on it.

  • Tribal SIS
  • Data Refresh
  • Upgrades
  • Customisation
04DATA

Database Administration

I administer every database in the environment. Day to day that's remediating SQL Agent jobs, running data processing and version upgrades, and the housekeeping that keeps systems fast and correct.

Every day I restore from backup sets to prove recovery actually works — because a backup only counts when it comes back.

  • SQL Server
  • SQL Agent
  • Backup / Restore
  • Data Processing
  • Upgrades
05CLOUD

Cloud & Hybrid Infrastructure

I design and operate hybrid cloud. I manage the VMware estate, migrate applications and data into the cloud, and codify the whole thing as infrastructure-as-code.

Terraform landing zones give a governed, repeatable foundation, wired into CI/CD so every change is reviewed, versioned and shipped with confidence.

  • VMware
  • Hybrid Cloud
  • Terraform
  • Landing Zones
  • CI/CD
06AI

AI & LLM Platforms

I build in-house AI capability. I stand up local LLM platforms on Ollama running models such as DeepSeek and Kimi, and design retrieval-augmented generation (RAG) systems over private institutional data.

And I evaluate the honest question underneath it all: where large models can genuinely add value in education — and where they can't yet.

  • Ollama
  • DeepSeek
  • Kimi
  • RAG
  • Local LLMs
